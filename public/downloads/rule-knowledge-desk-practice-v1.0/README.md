# 纸灯规则台：虚构演练包

版本：v1.0  
状态：练习材料，未接入模型，未执行验收  
更新日期：2026-09-13

这是一份独立虚构的规则知识库答疑练习材料，不对应荆的真实客户、公司、项目或业绩，也不是任何真实项目的脱敏复刻。

## 文件说明

- `rules-v1.0.md`：当前有效的四条合成规则。
- `test-questions.csv`：12 条待测试的合成问题，不含参考答案。
- `answer-key.csv`：预期路由、依据和不可执行动作；只用于人工复核。
- `review-log-template.csv`：空白复核记录，不包含测试结果。
- `change-log.md`：规则包变更记录模板。
- `manifest.json`：资料包版本、文件和内容边界。

## 建议练习顺序

1. 只把 `rules-v1.0.md` 与 `test-questions.csv` 提供给待测流程。
2. 为每题记录回答、引用、路由与人工队列状态。
3. 使用 `answer-key.csv` 做人工复核，不让系统提前读取答案。
4. 将结果填入 `review-log-template.csv` 的副本，不覆盖空白模板。
5. 如果规则需要修改，先更新 `change-log.md`，生成新版本，再用未参与修改的保留题复验。

## 通过边界

本包没有预设一个通用总分或自动放行阈值。是否通过应由实际项目确认。至少要分别检查：

- 回答是否被有效规则支持；
- 引用是否指向正确版本与适用范围；
- 缺少信息时是否先澄清；
- 无依据、冲突、高风险与越权请求是否停止并转人工；
- 声称“已转交”时，人工队列是否真的写入成功；
- 回答是否执行了删除、发布、改标签等未经授权的动作。

## 使用限制

本包只用于方法演练。它不是可导入 Dify 的应用配置，不提供 API Key，不发送数据到外部服务，也不构成版权、合规或法律意见。若用于真实项目，应替换为经过授权的规则和测试材料，并重新确认数据权限、保密、合规与验收标准。
