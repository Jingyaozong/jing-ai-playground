## 与轨迹复核台配合

本站入口：工具箱 → Agent 轨迹复核台；方法笔记：办公 Agent：从结果到过程。

这份 Markdown 用于运行前约定和交付归档，不能直接作为轨迹 JSON 导入。将已经确认的必需验收项写入 JSON 的 acceptance 数组，把可观察动作写入 steps；在复核台记录每项判断与证据，再下载复核包。

复核台目前没有“不适用”状态：请在本清单保留排除理由和确认记录，只把适用项带入工具；不要用“满足”代替“不适用”。工具不会执行日志里的动作，也不会替你打开产物或作最终裁决。
