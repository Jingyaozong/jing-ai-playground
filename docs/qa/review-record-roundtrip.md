# 复核记录文件往返检查

本地 QA 记录，不作为公开网页内容。使用合成测试文字，没有调用模型、上传素材或真实客户资料。

## 已验证流程（2026-10-03）

- 规则答疑验收台：载入 12 条虚构题，填写含逗号与换行的合成回答、批次与待讨论状态；实际下载复核 CSV，再通过文件选择器重新导入。取消保留当前修改，确认恢复下载时的回答与人工状态。
- 多模态评测记录台：填写合成批次、多行复核说明与待讨论状态；实际下载并导回 CSV。取消保留修改，确认恢复说明与状态。误导入规则台 CSV 时明确拒绝，当前记录保留。
- Agent 轨迹复核台：载入虚构日志，填写多行定位依据，实际下载并导回 JSON 复核包。取消保留修改，确认恢复原依据；独立虚构、未执行模型的来源标记仍保留。
- 规则台和多模态台：等待替换时，状态提示明确说明尚未替换，焦点落到提示；不再朗读上一次的导出反馈。
- 再次读取三个真实下载文件，追加合成续填字段后重新序列化和解析，深度比较一致；多模态台另实际检查导回后编辑会进入可读副本。

## 重测方法

1. 各工具新开空白页面，只用虚构演练或明确标注的合成测试字段。
2. 导出后核对下载目录里的新文件，再修改当前字段。
3. 导入刚下载的文件，先取消，核对修改仍在；重新导入并确认，核对原字段与人工状态恢复。
4. 恢复后继续填写，确认新修改进入下一次导出。文字副本与 Markdown 不能替代可恢复的 CSV / JSON。
5. 检查桌面与手机端的确认区、键盘焦点、标题换行和横向溢出。

浏览器自动化的 download 事件在本环境未返回，但文件实际写入了本机下载目录；本次以真实下载文件和重新导入结果核验，不以“已发起下载”提示作为完成证明。测试下载文件不纳入仓库。
