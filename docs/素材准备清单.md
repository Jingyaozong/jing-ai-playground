# 素材准备清单

网站里所有 `{……}` 都是等你填的占位符。填完以后页面会自动把它们换成正式文字、链接、图片或视频。
要填的文件只有一个：`app/data/profile.ts`。

先填第 1、2 节，半小时内能完成，填完首页就可以给人看。

## 1. 联系方式与简历

文件：`app/data/profile.ts`

| 占位符 | 填什么 | 说明 |
|---|---|---|
| `{邮箱}` | 求职用邮箱 | 填好后页面自动变成可点击的邮件链接 |
| `{简历 PDF 路径}` | `/resume.pdf` | 先把简历放到 `public/resume.pdf`，再填这个路径 |
| `{LinkedIn 或其他平台}` 和 `{平台主页链接}` | 平台名称和主页地址 | 可以加多条；没有就把 `links` 改成空数组 `[]` |

## 2. 真实项目数字

文件：`app/data/profile.ts`

**首页三个关键数字**（`stats`）

| 占位符 | 填什么 |
|---|---|
| `{30+ 人}` | 带过的团队规模 |
| `{+x%}` | Prompt-Image Match 指标提升幅度 |
| `{样本量}` | 累计评测 / 标注样本量 |

**四个项目**（`projects`）。每个项目的背景、任务、行动文案是按你给的要点起草的，请逐句对照真实情况修改。

| 项目 | 需要填的占位符 |
|---|---|
| AIGC 文生图评测 | `{公司 / 项目方}`、`{起止时间}`、`{我的角色}`、`{30+ 人}`、`{x% → y%}`（双人复核一致率）、`{+x%}` |
| 多模态图文匹配 / OCR（博彦科技） | `{起止时间}`、`{我的角色}`、`{团队规模}`、`{交付量}`、`{准确率 / 返修率}` |
| Dify 工作流自动化 | `{公司 / 项目方}`、`{起止时间}`、`{我的角色}`、`{处理量}`、`{节省工时 / 响应时间}` |
| 项目经理助理（海天瑞声） | `{起止时间}`、`{项目背景}`、`{项目数 / 交付量}` |

第四个项目是可选的。不想展示就从 `projects` 数组里删掉这一项。

## 3. 视频评测主案例（已用真实项目完成）

页面：`/cases/five-model-blind-test/`
数据：`app/data/blind-test.ts`（文字内容）和 `app/data/blind-test-scores.ts`（得分，由脚本生成）

这个案例用的是 2026 年 6 月的五模型交叉盲评，不需要再准备素材。需要你核对的只有文字：

| 待核对 | 位置 |
|---|---|
| “我做了什么”六条 | `blindTest.role` |
| 四条 Bad Case 的现象、原因假设、复测设计 | `blindTest.badCases` |
| 五条“局限与复盘” | `blindTest.limitations` |
| 五条结论 | `blindTest.conclusions` |

原始视频和打分表在 `视频评测/` 文件夹里，这个文件夹不进仓库。打分表有改动时，在仓库根目录运行 `python 视频评测/整理/build_scores.py` 重新生成得分文件。

想加分的话，可以用同样的题目对各产品的新版本补测一两题，放在页面最后做前后对比。

## 4. 人物一致性案例的视频

页面：`/experiments/forty-shots-one-character/`

页面顶部有一处 `{人物一致性视频路径}`。现在只有四格静态样本。有视频以后告诉我，我把它接成和主案例一样的播放器。

## 5. 分享图

每个页面的分享图已经按统一模板生成（标题 + 姓名 + 方向），在 `public/og/` 下。

| 待办 | 说明 |
|---|---|
| 首页分享图 | 现在用的是模板图。视频对比墙做好以后，截一张 1200×630 的图替换 `public/og.png` 和 `public/og/default.png` |
| 标题改了以后 | 运行 `npm run og` 重新生成全部分享图 |

## 6. 发布前检查

1. 确认 `app/data/profile.ts` 里没有剩余的 `{占位符}`。
2. 运行 `npm run verify:release`，全部通过。
3. 运行 `npm run acceptance`，确认“含 video 标签的页面”里出现了主案例页。
4. 把 `redesign/portfolio` 合并到 `main` 并推送，GitHub Actions 会自动部署。
