## 各项的检查方式

**源码标注词、元信息、站点地图、“虚构”一词**

```bash
npm run build && npm run acceptance
```

输出要点：导出页面 93 个，对外页面 18 个，设为 noindex 的归档页面 75 个；站点地图 18 条，没有 noindex 页面混入；18 个对外页面的 title、description（均不超过 80 字）、og:title、og:description、og:image 全部齐全，分享图文件都存在。

“虚构”一词说明：方法演示页标题下那一行写的是“方法演示，非真实项目数据”，所以页面里这个词的次数是 0。仓库里还有 6 处，都在规则答疑练习包的下载文件和它的校验脚本里，不是页面。

**内部死链、导航、页面结构**

```bash
npm run verify:navigation
```

其中“every exported page resolves its internal links”一项检查所有导出页面的站内链接。

**完整发布校验**

```bash
npm run verify:release
```

包含代码检查、类型检查、内容一致性、各工具的单元测试、构建、导出检查、导航测试，以及按 `/jing-ai-playground` basePath 模拟 GitHub Actions 环境的构建检查。全部通过。

**页面高度与字号**

在浏览器里测量。高度取 `document.documentElement.scrollHeight`。字号扫描把 92 个页面逐个载入 1280px 和 375px 宽的框架，展开所有折叠区，统计有文字且计算字号小于 12px 的元素，同时检查页面是否横向溢出。结果：两项都是 0。

## 没有达到或需要说明的地方

1. **视频只在一个页面里有。** 五模型交叉盲评案例页放了 15 条真实生成的视频（3 道题 × 5 款产品）。人物一致性案例页仍然只有静态样本。
2. **占位符会原样显示在页面上**，例如 `{30+ 人}`。填写前不建议发布。
3. **归档工具里还有约 100 种英文小标签**没有翻译，例如 `FIXED SHOT TASK`。它们现在是 13px 的正常字体。
4. **归档页面里还有约 25 处“无视频 / 待执行”类表述**，集中在实验数据和水线动作工具里。
5. **人物一致性案例页在手机上约 17.7 屏**，偏长。
6. **逐页人工看过的页面有限。** 截图确认过的约 8 个，脚本量化检查过全部 92 个。归档页面的版式由批量规则转换，个别页面可能有不协调的细节。
7. **robots.txt 对这个站点不起作用。** 项目站点部署在 `/jing-ai-playground/` 子路径下，搜索引擎只读域名根目录的 robots.txt。归档页面的排除靠每页的 `noindex` 实现，这一项不受影响。
8. **分享图用 Noto Sans SC 渲染**（开源字体）。重新生成需要本机装有这个字体，Windows 11 自带。
