同一个房间在 AI 视频里可能有很多种“换房间”的方式：窗户从左墙跑到右墙，床忽然换了方向，桌上多出一盏灯，门后出现新的走廊，木地板变成水泥，雨夜的蓝光下一镜又变成午后暖阳。

每一张图都可以很好看，但它们不再共享同一个空间。问题不只是 Prompt 少写了几个形容词，而是制作过程没有先定义：**哪些事实构成这个场景的身份，哪些变化只是镜头选择，哪些变化必须由故事解释。**

> [!KEY POINT]
> 场景一致性不是让所有镜头长得一样，而是让观众相信摄影机在同一个空间里换了位置。固定的是空间事实，变化的是机位、景别、人物动作和被剧情允许改变的状态。

## 一张好看的场景图，不等于一个可拍的场景

单张参考图只能展示一个角度。它可能没有告诉模型：画外还有什么、门通向哪里、窗户与桌子的相对位置、反打以后主光应该从哪边来。

[Runway 关于长视频制作的官方工作流](https://help.runwayml.com/hc/en-us/articles/26871350018835-How-to-create-longer-videos-and-films)建议为角色准备不同角度的 character plates，也提出为场景制作不同角度与情境的 environment plates，并把多个场景并排检查整体气氛与视觉风格。官方说明同时指出，仅从单一角度参考人物时，模型缺少其他角度的信息，仍可能产生细微变化。这个限制同样值得用于理解场景：**参考图提供了可见证据，但不会自动补全不可见空间。**

因此不要只保存“最终选中的一张图”。至少要留下三种资料：

1. 场景母版：确定这个地点的总体身份；
2. 空间关系：用平面图或文字说明门、窗、家具与人物区的位置；
3. 环境 Plates：展示真正需要拍摄的不同方向和景别。

## 用六层账本定义场景身份

| 场景层 | 需要记录什么 | 容易出现的漂移 |
| --- | --- | --- |
| 空间结构 | 房间形状、门窗数量与位置、主要家具关系 | 多出一扇窗、门换墙、走廊方向改变 |
| 机位与轴线 | 摄影机所在区域、人物运动方向、是否越轴 | 反打像换房间、左右关系突然翻转 |
| 道具状态 | 位置、数量、朝向、开合、完好程度、持物关系 | 杯子增殖、信封重新封好、灯忽然亮起 |
| 材质与细节 | 墙面、地面、家具材质、磨损与年代 | 木地板变石材、旧墙突然像新装修 |
| 光线 | 主光来源、方向、高度、软硬、色温与亮暗层级 | 窗外光换边、夜景变白天、阴影方向冲突 |
| 天气与声音 | 雨雾风雪、地面湿度、环境底与空间混响 | 雨量重置、地面忽干、房间声场突然改变 |

六层不需要写成一篇小说。它们的作用是把“像同一个地方”拆成可以观察和比较的事实。

## 第一层：先画空间，不要先写氛围

“旧公寓、电影感、孤独、暖黄色灯光”能描述气质，却没有定义空间。先把房间写成简单关系：

```text
北墙：一扇窄窗，窗下是旧木桌。
东墙：唯一的门，向房间内打开；门外连接狭长走廊。
西墙：低书柜，顶层放一台红色收音机。
南侧：单人床，床头靠西，人物醒来时面向房间中央。
固定关系：桌在窗下；门与书柜相对；床不遮挡门。
```

这段文字不是要原样塞进每条 Prompt，而是制作团队的场景事实。每个镜头只调用当前能看见、并且与构图有关的部分。

### 再做一张极简平面图

```text
                 北 / 窗
        ┌─────────────────┐
        │      旧木桌      │
西 /   │                  │  东 / 唯一的门 → 走廊
书柜   │      活动区       │
        │  单人床          │
        └─────────────────┘
                 南
```

平面图不需要精确建筑比例。它只负责回答：物体在哪面墙、人物从哪里进入、摄影机能站在哪里，以及下一个镜头为什么看得见某个背景。

## 第二层：建立机位图，而不是让每镜重新发明角度

可以在平面图上标出少量可用机位：

```text
C1 门侧广角：看见床、桌与窗，负责建立空间。
C2 窗侧中景：看向人物与门，人物朝画面右侧移动。
C3 桌面特写：只看信封与手，背景虚化但保留窗光方向。
C4 走廊反打：看向房门，重新建立门外空间。
```

机位编号的价值不在于限制创意，而是让分镜能说清楚“这次摄影机去了哪里”。如果镜头 B 需要一个完全不同的角度，就在机位图上新增位置，并检查它与人物方向、背景结构和光线来源是否成立。

[Adobe 对连续性剪辑的说明](https://www.adobe.com/creativecloud/video/hub/ideas/what-is-continuity-editing-in-film.html)把道具、服装、时间与空间的稳定视为连续性的一部分，也用 180 度规则和视线匹配帮助观众理解人物与环境的关系。对 AI 场景而言，轴线不仅决定人物看向哪边，还决定背景中的门、窗和家具应该怎样重新排列在画面里。

## 第三层：场景母版和环境 Plates 怎样分工

### 场景母版

选择最能说明空间身份的一张画面。它应该清楚展示主要材质、核心家具、光线来源和整体色彩，不一定是最戏剧化的镜头。

### 环境 Plates

根据真实分镜需要，补充：

- 建立全景；
- 朝向门的中景；
- 朝向窗的反向机位；
- 桌面或关键道具区；
- 连接空间，例如门外走廊；
- 如果剧情需要，补充白天 / 夜晚或变化前 / 变化后的独立版本。

[Runway 的 References 指南](https://help.runwayml.com/hc/en-us/articles/40042718905875-Creating-with-Gen-4-Image-References)明确展示了使用参考图生成同一环境的不同角度、焦点和物体画面，也提醒：加入更多参考和更多变量会增加变化空间，结果仍可能偏离原始设想。因此 Plates 是增加证据，不是保证。

### 构图草图

如果平台支持草图或标注，可以用框、箭头和文字提示空间边界。Runway 的 [Advanced References](https://help.runwayml.com/hc/en-us/articles/41170686463635-Advanced-References-Use-Cases)示例使用 bounding boxes 引导构图，也展示了把室内空间与家具参考组合起来的方法。

即使不使用特定平台，也可以自己画一张低成本构图卡：

```text
左 1/3：人物近景
右后方：唯一的门，保持关闭
左后方：窗户只露出一部分
画外：床与书柜，本镜不要求出现
```

这比一句“同样的房间，不要改变布局”更容易检查。

## 第四层：把道具写成状态，不只写成名词

“桌上有信封”不足以保持连续。道具有自己的状态变化：

| 道具 | 初始状态 | 镜头 04 后 | 镜头 07 后 | 不允许无因变化 |
| --- | --- | --- | --- | --- |
| 白色信封 | 封口完整，放在桌面中央 | 被右手拿起 | 封口撕开，信纸抽出 | 自动重新封好、换成其他颜色 |
| 红色收音机 | 书柜顶层，关闭 | 不变 | 指示灯亮起 | 跑到桌面、数量增加 |
| 房门 | 关闭，门把水平 | 不变 | 打开一条缝 | 门型改变、开合状态倒退 |
| 水杯 | 桌面左后方，半杯水 | 被碰到但未倒 | 仍在原位 | 突然装满、换到人物右手 |

状态表应该记录**动作前和动作后**。只要剧情改变了道具，就把新状态带到后续镜头；不要继续复制最初的场景描述。

## 第五层：光线需要方向，不只是“电影感”

“暖光”“冷蓝夜景”“柔和电影光”描述了外观，却没有告诉反打镜头怎样继续同一盏灯。

光线账本至少记录：

```text
时间：雨夜，外部没有日光。
主光：来自北墙窗外的冷蓝街灯；人物靠窗一侧更亮。
室内光：桌面右后方一盏低亮度暖灯；只照亮桌面与手。
阴影：整体柔和，人物背向窗时脸部偏暗。
亮暗层级：窗最亮，桌灯次亮，走廊比房间暗。
允许变化：门打开后，走廊暖光进入地面；其他光源不变。
```

反打镜头不能机械复制“画面左侧来光”。摄影机换边以后，光源在画面中的左右位置可能变化，但它在房间里的真实位置不能变。

后期仍然需要逐镜比较。[Adobe Premiere 的颜色匹配文档](https://helpx.adobe.com/premiere/desktop/correct-color/add-color-effects/match-color-between-shots.html)提供参考帧、目标帧和并排 / 分割比较，用于检查同一场景或不同场景的颜色与光线外观。颜色匹配可以修正曝光、色温和整体倾向，却不能修复窗户换墙、家具消失或阴影来自错误方向。

## 第六层：天气也有连续状态

雨、雾、雪、风和湿地反光都不是一次性的氛围词。它们会影响场景的多个层面：

```text
雨：持续中雨；窗玻璃有细密水痕。
风：较弱；窗帘偶尔轻动，不持续大幅飘动。
地面：走廊入口附近有湿鞋印，房间内部保持干燥。
远景：能见度中等，街灯边缘有轻雾。
声音：连续雨声；关门后高频减弱，但不完全消失。
```

如果镜头跨越了时间，就明确写变化：雨逐渐变小、地面开始积水、天色变亮。变化有方向时，它是故事时间；每镜随机重置时，它才是连续性错误。

## 参考图应该分角色，不要一张图承担一切

一个镜头可能同时需要：

- 人物参考：脸、发型、服装与比例；
- 场景参考：结构、材质与固定家具；
- 道具参考：信封、收音机或特殊装置；
- 构图参考：人物与背景在当前镜头里的位置；
- 风格参考：色彩、质感和媒介效果。

这些参考并不总能同时输入同一个模型，也不应该假定平台会自动理解每张图负责什么。Google Cloud 的 [Veo 参考图文档](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/video/generate-videos-from-references)把参考图作为引导视频内容的输入，并按具体模型和参考类型说明支持范围；Runway 也为 References 设置了具体数量与工作流限制。真正执行时，应以当前产品文档为准，并在测试记录中保存模型、版本、参考组合和 Prompt。

## 把场景事实和镜头变量分开写

下面是一种结构示例，不是已经验证的模型语法：

```prompt
场景锚点：狭小旧公寓。北墙只有一扇窄窗，窗下是旧木桌；东墙只有一扇深绿色木门；西墙低书柜上放红色收音机；深色木地板，墙面有轻微剥落。

当前状态：雨夜。房门关闭；白色信封已经拆开，信纸在人物右手；红色收音机指示灯关闭。

当前镜头：C2 窗侧中景，摄影机看向人物与东墙房门。人物位于画面左侧，朝画面右侧看门。窗外冷蓝光照亮人物左侧轮廓，桌灯暖光只落在手和信纸上。

运动：人物缓慢抬头；摄影机固定；窗帘只有很轻的风动。

验收锚点：唯一的东墙房门、窗下木桌、红色收音机仍在西墙书柜、拆开的白色信封、冷窗光与暖桌灯方向不变。
```

“场景锚点”和“当前状态”需要跨镜继承；“当前镜头”和“运动”允许变化；“验收锚点”只保留本镜真正看得见且重要的 3–5 项。

## 不要逐张挑最好看，要成组比较

单张筛选会偏向构图最漂亮、细节最多或冲击力最强的画面，却可能忽略它与其他镜头是否属于同一空间。

把候选图按场景放在同一张板上，至少比较：

1. 门窗与家具是否仍处在同一关系；
2. 相邻机位能否用平面图解释；
3. 道具状态有没有倒退或增殖；
4. 墙面、地面和家具材质是否一致；
5. 主光是否仍来自同一个实际位置；
6. 天气、湿度和环境声是否处在同一时间状态；
7. 哪些差异可以后期修，哪些必须重做画面。

如果一张图最好看但破坏了空间结构，应把它当成新场景候选，而不是强行塞回原场景。

## 常见场景漂移，先修哪一层

| 症状 | 先检查 | 优先处理 |
| --- | --- | --- |
| 窗户和门不断换墙 | 空间结构、环境 Plates、构图草图 | 锁定平面图与当前机位可见边界 |
| 反打像进入另一间房 | 轴线、机位编号、背景关系 | 用建立镜头或平面图验证摄影机位置 |
| 桌椅数量变化 | 固定家具与临时道具是否混写 | 建立不可增减清单，只描述当前可见部分 |
| 道具每镜恢复初始状态 | 状态表没有随动作更新 | 为每镜记录进入状态与离开状态 |
| 夜景忽冷忽暖 | 主光方向、色温、曝光与参考帧 | 先修光源逻辑，再做后期颜色匹配 |
| 材质像换了装修风格 | 场景参考只强调氛围，没有材料锚点 | 明确地板、墙面、家具材质与磨损 |
| 雨量和地面湿度重置 | 天气被每镜独立描述 | 建立天气阶段并沿时间线推进 |
| 背景稳定但人物像被贴上去 | 人物光线与场景光线不一致 | 让人物受光、阴影和色温服从场景光源 |

## 四镜最小场景测试

不要一开始生成整个场景。先用四个功能不同的镜头测试空间是否真的成立：

1. **建立镜头**：同时看见两项以上固定结构，例如窗、桌和门；
2. **同侧中景**：人物进入画面，背景仍能确认机位位置；
3. **关键特写**：只看道具和手，但光线、材质与状态接得上；
4. **反向机位**：最容易暴露空间、轴线和主光是否被真正定义。

四镜放进一张比较板和真实时间线。失败后一次只修一层：先修结构，再修道具，再修光线与颜色。不要同时更换场景参考、人物参考、构图和所有形容词，否则下一轮无法知道哪项起作用。

## 生成前检查表

- [ ] 场景身份已经拆成空间、机位、道具、材质、光线和天气六层；
- [ ] 有一张能说明核心结构的场景母版；
- [ ] 已为真正需要的角度准备环境 Plates，而不是从单图猜完整空间；
- [ ] 门、窗、固定家具和连接空间已经写进简易平面图；
- [ ] 每个镜头知道摄影机站在哪里，是否跨越轴线；
- [ ] 关键道具有进入状态、离开状态和不允许无因变化项；
- [ ] 光线写清实际来源、方向、色温和允许变化；
- [ ] 天气、地面湿度和环境声沿故事时间推进；
- [ ] 人物、场景、道具、构图与风格参考的职责已经区分；
- [ ] 本镜验收锚点控制在 3–5 项，并且都能在画面中看见。

## 生成后按组验收

1. **缩略图看结构**：门窗、家具和人物位置是否像同一空间；
2. **并排看材质**：墙、地面、家具与道具细节是否突然换代；
3. **按时间看状态**：门、信封、灯和天气是否只向前变化；
4. **灰度看光线**：亮暗层级和阴影方向是否属于同一套光源；
5. **颜色看参考帧**：曝光、白平衡与色温是否需要后期匹配；
6. **放进时间线看切点**：单张可接受的差异，剪在一起是否会暴露；
7. **记录重做原因**：标明是结构、道具、材质、光线还是天气问题。

## 最后记住这句分工

**参考图负责提供证据，平面图负责解释空间，状态表负责让场景沿时间前进。**

不要要求模型“保持同一个房间”，却每一镜都让它重新猜门在哪里、灯从哪边照、信封是否拆开。先把场景变成一组可检查的事实，再让摄影机在这些事实中自由移动。
