AI 视频里的“有声音”，不是一个开关，而是至少五件不同的事：角色说了什么、声音怎样表演、嘴型是否对上、空间里一直有什么声音，以及某个动作发生时响了什么。

如果把它们全部塞进一条视频 Prompt，失败以后很难判断问题来自台词、人物表演、画面运动还是混音。更稳妥的顺序是：**先选声音路线，再分配每一层的责任，最后按层验收。**

> [!KEY POINT]
> 对白决定信息，表演决定语气，口型连接脸与声音，环境声建立空间，音效标记动作，音乐组织情绪。它们可以在同一次生成里出现，但不应该在制作计划里混成一项。

## 先把六层声音拆开

| 声音层 | 回答的问题 | 适合记录什么 |
| --- | --- | --- |
| 对白 / 旁白 | 观众需要听懂什么？ | 精确台词、说话人、是否画外音 |
| 声音表演 | 这句话怎样被说出来？ | 语气、速度、停顿、呼吸、音量变化 |
| 口型与面部 | 谁正在说，嘴和表情怎样同步？ | 可见说话者、脸部角度、遮挡、表演输入 |
| 环境声 | 这个空间一直是什么感觉？ | 雨声、空调低鸣、远处车流、房间底噪 |
| 动作音效 / Foley | 哪个动作需要被听见？ | 脚步、纸张、门锁、杯子落桌、提示音 |
| 音乐 | 情绪和段落怎样被组织？ | 进入点、退出点、强弱、是否压住对白 |

这张表最重要的用途，是防止同一个任务被写两次。例如，“雨夜公交站”可以由画面给出，也可以由环境声建立；但“她听见消息提示音后才抬头”必须在时间线上说明声音与动作的先后。

## 先选路线，不要先写 Prompt

目前常见的 AI 视频声音工作流，可以先分成三条。

| 路线 | 最适合 | 主要优势 | 主要代价 |
| --- | --- | --- | --- |
| 原生音视频生成 | 一次性探索气氛、短对白与声画联动 | 画面、对白、环境与音效可在同一提示中共同生成 | 任何一层不满意，都可能需要重新生成整段 |
| 静音画面 + 后期声音 | 画面优先、需要逐层控制和反复修改的镜头 | 对白、音效、环境和音乐可以独立替换 | 需要剪辑、对点和混音；嘴部近景不一定适用 |
| 表演 / 音频驱动口型 | 正面或近景说话、角色表演是镜头核心 | 先确定节奏和表演，再把脸部运动迁移给角色 | 对输入脸、表演视频、时长与清晰度更敏感 |

这三条路线不是产品排名。它们的区别是：**你愿意把哪一项交给模型一次决定，哪一项必须留到后面单独修改。**

## 路线一：原生音视频，让声音参与画面生成

[Google Cloud 的 Veo 3.1 Prompt 指南](https://cloud.google.com/blog/products/ai-machine-learning/ultimate-prompting-guide-for-veo-3-1/)把 Dialogue、Sound effects 和 Ambient noise 分开说明：特定台词可以用引号标出，音效和环境声则分别描述。官方文档也说明这些音频能力仍在持续改进，因此它更适合作为一个明确、可复现的生成方案，而不是“写一次就能完成混音”的承诺。

可以把提示写成四段，而不是一整段形容词：

```prompt
画面：固定中近景。她坐在雨夜的公交站里，手机屏幕突然亮起。
对白：她低声说：“这不是今天拍的。”
音效：手机提示音在她抬头前响一次；外套布料轻微摩擦。
环境声：持续但克制的雨声，远处偶尔有车辆驶过。
```

这是一条**结构示例**，不是已验证的模型输出。不同平台对引号、标签、语言和时长的处理会变化，真正测试时应保存模型版本与生成设置。

### 原生音视频适合什么镜头

- 声音和动作关系简单，例如“铃声响起，她回头”；
- 对白短，只有一个主要说话者；
- 环境声对气氛很重要，但不要求后期级别的精确混音；
- 当前目标是探索镜头，而不是锁定最终表演；
- 即使重新生成整段，也不会破坏已经确认的大量后期工作。

### 什么时候不要继续往 Prompt 里加

- 两个人轮流说长对白，还要精确控制每句停顿；
- 同时要求大幅人物动作、复杂运镜、多个音效和身份稳定；
- 必须逐字保留台词、品牌发音或专有名词；
- 画面已经通过，只想更换一句台词或一个脚步声；
- 音乐、环境和对白需要分别调音量或做版本比较。

这些情况更适合把声音拆出来，而不是继续让一条 Prompt 承担整个后期。

## 路线二：先做静音画面，再建立声音时间线

后期配声不代表“最后随便加点音乐”。它的优势是让每一层都能独立替换。

[Adobe Firefly 的官方说明](https://helpx.adobe.com/firefly/web/work-with-audio-and-video/work-with-audio/text-to-sound-effects.html)明确区分了能力边界：Generate sound effects 用来生成音效和环境声，不能生成音乐或对白；它也允许把不同声音放在独立轨道上，移动、裁切和调节音量。Adobe 还提供用人声表演控制音效时机与能量的方式，但那段录音只负责引导音效，并不会变成对白。

一个容易维护的声音时间线可以这样排：

```text
A1  对白 / 旁白：准确台词与最终表演
A2  环境底：整镜连续的雨声、室内低鸣或街道远声
A3  同期动作：脚步、衣料、呼吸、纸张、门把手
A4  重点音效：消息提示、撞击、机械启动等叙事节点
A5  音乐：只在确认对白与动作节奏后加入
```

不需要每一镜都用满五层。空镜可能只有环境与音乐；一个近景对白镜头，也许只保留对白、呼吸和很轻的空间底。

### 为什么先铺环境底

环境声负责把不同镜头粘在同一个空间里。两个画面都在同一间房，如果每次切镜时底噪突然消失、雨声方向变化、混响长度完全不同，观众会先听见“剪辑缝”。

先建立一条连续的 Room tone / Ambience，再在上面增加动作音效，会比每镜单独生成一段“完整声音”更容易保持连续。

### 音效要写成可对点的事件

不要只写“有纸张声”。把它写成：

```text
00:01.4 右手碰到信封：一次轻微纸张摩擦
00:02.2 手指压住封口：更短、更近的一次折压声
00:04.8 画面外手机亮起：单次提示音，随后不重复
```

时间点不必在分镜阶段精确到最终帧，但必须说明它跟哪个可见动作发生关系。这样才能判断声音是在动作前、动作中还是动作后。

## 路线三：先录表演，再驱动角色说话

如果镜头的主要任务是“让这个角色把这句话说出来”，就应该先确定表演节奏，而不是让视频模型同时发明台词长度、嘴型、表情和身体动作。

Runway 已在 2026 年 5 月停用旧的独立 Lip Sync 工具，并把 [Act-Two](https://help.runwayml.com/hc/en-us/articles/42311337895827-Performance-Capture-with-Act-Two)作为替代方向。Act-Two 使用一段人物表演视频和角色图像或视频：表演输入提供动作、表情、音频与手势，角色输入决定最终角色。

官方给出的输入建议包括：

- 表演视频尽量只有一个主体，脸始终可见；
- 最远以腰部以上构图，光线清楚，面部特征明确；
- 不要在表演中切镜，动作尽量自然，不要突然大幅变化；
- 角色输入也应是单一主体，并清楚看见眼睛和嘴；
- 使用角色视频时，长度尽量接近表演长度，否则可能出现反向循环来补足时长；
- 清晰、音量与音高相对稳定、背景噪音较少的录音更有利于结果。

这些是特定产品当前的输入规范，不应该直接冒充所有口型工具的通用限制。但它们揭示了一个更普遍的制作原则：**口型任务需要清楚知道谁在说、脸在哪里、这一句到底说多久。**

### 多人对白为什么适合拆镜

Runway 的多人对白教程仍以单角色输入为基础：分别处理每个角色，再在剪辑软件里合成。这意味着一镜里同时让两张脸准确轮流说话，会明显增加隔离、对齐和合成工作。

更容易执行的分镜方式是：

```text
镜头 A：角色甲说话，角色乙只做非语言反应
镜头 B：角色乙回答，角色甲留在画外或只做背影反应
镜头 C：双人反应镜头，不安排新的精确对白
```

这不是要求所有对话都使用正反打，而是在生成阶段让每一镜只有一个明确的嘴型任务。

## 台词多长，不要用统一字数公式猜

中文、英文、数字、专有名词、情绪停顿和表演速度都会改变台词时长。不存在一条能跨角色、跨语言、跨模型使用的“每秒固定字数”。

更可靠的方法是：

1. 用准备采用的语气真实读一遍或生成一版临时配音；
2. 保留开口前的反应时间、句中停顿和说完后的表情停留；
3. 用实际录音长度反推镜头时长；
4. 如果产品有时长上限，先拆台词和镜头，不要强行加速；
5. 把最终音频与使用的文本版本绑定，避免后面改词却仍沿用旧口型。

可以把每句对白记录成：

```text
说话人：她
精确台词：这不是今天拍的。
表演方向：压低声音；“今天”前短暂停顿；说完后保留一次呼吸
临时录音长度：实际测量后填写
镜头内可见嘴型：是
路线：表演驱动 / 原生音视频 / 画外配音
```

## 同一句台词，三种路线怎样选

假设台词是：“如果我明天不记得你，就把这封信再给我一次。”

### 只需要故事信息

人物背对镜头，或者声音来自画外。优先考虑后期对白。画面可以独立生成，不必为看不见的嘴型增加约束。

### 需要一句短促反应

人物只说“别打开”，随后立刻转身。可以先测试原生音视频，因为台词、动作和音效关系简单；若文字或发音不稳定，再切换到后期或表演驱动。

### 需要保留完整表演

近景里能看见停顿、呼吸、犹豫和嘴部动作。先录表演或临时音频，根据实际长度设计镜头，再进入口型 / 表演驱动流程。

## 一张可以写进分镜的声音卡

每个重要镜头只需要填七项：

```text
镜号：
声音路线：原生音视频 / 后期配声 / 表演驱动
对白：说话人 + 精确文本 + 是否画外
表演：语气 + 速度 + 停顿 + 呼吸
环境声：持续声音 + 远近 + 空间质感
动作音效：事件 + 大致时间点 + 前后关系
音乐：进入 / 退出 / 是否让位给对白
验收重点：本镜只写最重要的 2–3 项
```

例如：

```text
镜号：07
声音路线：后期配声；人物不露正面嘴型
对白：她，画外音，“这不是今天拍的。”
表演：轻声；“今天”前停顿；尾音不做戏剧化上扬
环境声：连续雨声；站棚内较闷，远处车辆偶尔经过
动作音效：00:01.8 手机提示音；必须早于人物抬头
音乐：无
验收重点：提示音先于动作；台词清楚；雨声跨切镜不断
```

这仍然是一份制作模板，不是实际完成的配音或混音记录。

## 常见问题，先检查哪一层

| 症状 | 先检查 | 不要立刻做什么 |
| --- | --- | --- |
| 台词内容错误或漏字 | 对白文本、产品语言支持、是否需要换路线 | 只在画面 Prompt 后继续追加形容词 |
| 嘴型跟不上 | 实际音频长度、脸部可见度、输入是否单人 | 先加更复杂的运镜和身体动作 |
| 人物会说话但表情僵硬 | 驱动表演、面部清晰度、表演幅度 | 只更换声音，不检查表演输入 |
| 音效有了却没有重量 | 起音时间、远近、持续长度、是否与动作对齐 | 同时叠更多互相竞争的音效 |
| 切镜时空间突然变化 | 连续环境底、响度、混响和声像 | 每镜单独生成一段完整声音后直接拼接 |
| 音乐盖住对白 | 音量关系、频段、进入点与退出点 | 让说话者读得更急、更响来对抗音乐 |
| 一镜怎么都对不齐 | 本镜是否同时承担对白、复杂动作与复杂运镜 | 继续增加约束而不拆镜 |

## 生成前检查表

- [ ] 已经选择原生音视频、后期配声或表演驱动中的一条主路线；
- [ ] 精确台词与“怎样说”分开记录；
- [ ] 看不见嘴的对白没有被强行当作口型任务；
- [ ] 能看见嘴的镜头已经确认说话者、脸部角度和遮挡；
- [ ] 台词时长来自试读或临时音频，而不是统一字数公式；
- [ ] 环境声、动作音效和音乐没有混成一句“氛围感声音”；
- [ ] 每个动作音效都知道大致发生在动作前、中还是后；
- [ ] 同一空间的环境底、远近与混响准备保持连续；
- [ ] 本镜最重要的声音验收项不超过三项。

## 生成后按层验收

1. **信息**：台词是否完整、顺序正确、能被听懂；
2. **表演**：语气、速度、停顿和呼吸是否服务人物；
3. **口型**：开口与收口是否对上，牙齿、嘴唇和下巴是否稳定；
4. **声画关系**：音效是否落在正确动作上，声音方向和远近是否合理；
5. **连续性**：切镜前后环境底、混响和响度是否突然跳变；
6. **混音**：对白是否被音乐或音效遮住，重点声音是否真的被听见；
7. **可修改性**：如果只错一层，能否单独替换，而不是重做整镜。

## 最后记住这句分工

**先决定谁负责说话，再决定谁负责让嘴动，最后才把空间和情绪铺进去。**

如果一个镜头同时要求精确长对白、明显口型、复杂动作、大幅运镜、多个音效和稳定角色，最有效的修改通常不是写得更长，而是把镜头拆小，把声音拆层。
