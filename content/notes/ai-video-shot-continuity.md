两个镜头都很好看，剪在一起却可能像两个不同的世界：人物忽然换边，视线找不到对象，抬到一半的手重新开始，门把手换了一只，道具消失，雨声在切点突然断掉。

这类问题不能靠单独评价镜头 A 或镜头 B 解决。连续性是**两个镜头之间的关系**。真正需要检查的是：A 在离开时留下了什么状态，B 在进入时是否接住了它。

> [!KEY POINT]
> 镜头 A 的尾部是一个承诺，镜头 B 的开头负责兑现。跨镜连续性不是让两镜完全一样，而是让该保持的保持、该变化的变化，并让观众知道变化为什么发生。

## 先把检查单位改成 A → B

不要只写：

```text
镜头 A：她站在门口。
镜头 B：她进入房间。
```

改成一张交接卡：

```text
镜头 A 出口：她在画面右侧，右手握住门把，身体朝画外左侧转动；门刚打开一条缝。
镜头 B 入口：近景承接右手继续推门；动作不重新开始；她仍朝画面左侧移动。
切点锚点：右手、门把、向左运动、门缝宽度、连续雨声。
允许变化：景别从中景变近景；室外雨声变得更闷。
```

“切点锚点”不是要求模型复制整张画面，而是列出观众在切点会追踪的少数事实。

## 连续性至少有六条线

| 连续线 | 需要保持什么 | 可以有意改变什么 |
| --- | --- | --- |
| 人物身份 | 脸、发型、服装、配饰、体型 | 表情、姿态、被剧情解释的外观变化 |
| 空间与方向 | 人物相对位置、进出方向、摄影机所在轴线 | 经过中性镜头或明确运动后重新建立方向 |
| 视线 | 谁看谁、看向画面的哪一侧、目标大致高度 | 角色主动转头、目标移动或主观视点改变 |
| 动作与时间 | 动作阶段、速度、身体重心、物体接触状态 | 景别、角度，以及被切点省略的中间时间 |
| 场景事实 | 道具位置、门窗状态、光线方向、天气 | 有叙事原因的时间推进或空间变化 |
| 声音 | 对白节奏、环境底、动作音效、空间远近 | J / L Cut、主观声音、刻意的静音或声场转换 |

六条线不需要每镜全部锁死。一个空镜可能只关心空间、光线与环境声；一个人物近景可能优先检查身份、视线和对白。

## 空间方向：先画一条轴线

[Adobe 对连续性剪辑的说明](https://www.adobe.com/creativecloud/video/hub/ideas/what-is-continuity-editing-in-film.html)把 180 度规则列为保持空间地理关系的基本方法：在人物之间想象一条轴线，摄影机保持在轴线同一侧，画面中的左右关系就更容易稳定。

例如两个人面对面：

```text
角色甲  ----------------  角色乙
        对话 / 视线轴线

摄影机只在轴线同一侧选择机位：
甲持续朝画面右侧看，乙持续朝画面左侧看。
```

如果下一镜突然越过轴线，两个人可能看起来朝同一方向说话，或者像互换了位置。对于 AI 生成，还可能同时出现背景结构、光线方向和人物外观变化，让空间错误更难诊断。

### 180 度规则不是法律

[Adobe 的专题说明](https://www.adobe.com/creativecloud/video/discover/what-is-the-180-degree-rule.html)也强调，可以为了混乱、权力变化或视角转换而有意越轴。[BFI 对小津安二郎的分析](https://www.bfi.org.uk/sight-and-sound/ozu-yasujiro-master-time)则讨论了导演如何系统性地违背传统连续性语法。

因此正确问题不是“能不能越轴”，而是：

- 越轴是否表达了明确叙事变化；
- 观众是否还有其他空间锚点；
- 这一处不连续是剪辑决定，还是模型意外改变了方向；
- 如果删掉越轴，场景意义是否会变弱。

如果没有答案，先保持轴线通常更便于排错。

## 视线：镜头 B 要回答镜头 A 的问题

视线匹配不只是“脸朝左还是朝右”。它至少包含：方向、高度、目标距离和注意力变化。

镜头 A 中人物突然看向画外右上方，镜头 B 最自然的问题是：那里有什么？如果 B 切到桌面左下角的一只杯子，空间关系就会显得不可信，除非中间有新的动作或机位解释。

可以把视线写成：

```text
镜头 A 出口：她的视线从手机移到画外右上方，头部只转动少量。
镜头 B 入口：高处窗户的近景；主体落在画面右侧附近。
```

Adobe 还提到 Eye trace：观众在上一镜最后注视的位置，会影响下一镜首先寻找的位置。除了人物视线，还可以用高亮区域、颜色、运动或构图，把注意力从 A 的落点引向 B 的入口。

## 动作匹配：不要让动作在切点重新开始

Match on action 的核心，是第二个镜头继续第一个镜头已经开始的动作。Adobe 的例子包括：手碰到门把，下一镜接门打开；动作本身跨过切点，两个机位因此被感知为同一个时间过程。

AI 镜头常见的问题不是“没有相同动作”，而是动作阶段不一致：

```text
错误交接：
A 尾部：手已经握紧门把，门开始转动。
B 开头：手再次从远处伸向门把。

正确交接目标：
A 尾部：手接触并开始下压门把。
B 开头：门把继续下压，门随即打开。
```

交接时至少记录四项：

1. 动作进行到哪一阶段；
2. 身体或物体正朝哪个方向移动；
3. 切点前后的速度是否接近；
4. 接触关系是否保持，例如手是否仍握住物体。

### 不必把同一帧复制两次

如果镜头 A 的最后一帧直接成为镜头 B 的第一帧，视觉状态更容易对齐，但剪辑时可能出现重复停顿。[Runway 的图生视频指南](https://help.runwayml.com/hc/en-us/articles/48324313115155-Image-to-Video-Prompting-Guide)建议使用上一段的最后帧开始下一段，并在编辑器里调整时间、移除共享帧；其 Workflows 文档也提供自动提取 Last Frame 的节点。

共享帧解决的是“起点一致”，不自动解决：

- 新镜头的动作速度是否延续；
- 摄影机运动方向是否突然变化；
- 角色身份和背景是否在后续几帧漂移；
- 声音是否在拼接处重复或断裂。

所以最终仍然要在时间线上检查切点前后，而不是只对比两张静态图。

## 什么时候用上一镜尾帧，什么时候重新做入口帧

### 直接使用上一镜尾帧

适合把一个长动作延伸成多段、摄影机角度不变、画面构图希望连续推进的情况。它更像“继续同一个镜头”。

### 重新生成入口关键帧

适合换景别、换机位或切反应镜头。此时不需要复制整张尾帧，而是从切点账本重新构图，同时保留人物、方向、视线、动作阶段和道具状态。

### 用过渡镜头重新建立空间

适合需要越轴、跨地点、跨时间或大幅改变光线的情况。一个空镜、特写、遮挡、运动模糊或明确转场，可以告诉观众旧的空间关系已经结束。

## 人物与道具：建立“不能突然变化”的账本

跨镜人物一致性不能只写“同一个女孩”。需要把身份拆成可见锚点：脸型、发型、服装、配饰和比例。道具也一样：拿在左手还是右手、打开还是关闭、是否有损坏、位于桌面哪一侧。

[Runway 的 References 文档](https://help.runwayml.com/hc/en-us/articles/40042718905875-Creating-with-Gen-4-Image-References)说明参考图可以用于保持角色和场景特征，并建议使用光线自然、表情中性、特征清晰的输入。这个能力有助于建立稳定素材，但参考图仍不能替代切点记录。

可以为相邻两镜保留：

```text
人物锚点：短黑发；左耳银色圆耳钉；米色风衣；右手戴黑表。
道具状态：白色信封；封口已撕开；右手持信，文字面朝人物。
不可漂移：耳钉换边、手表消失、信封重新封闭、持物手互换。
```

## 光线与色彩：检查方向，不只检查“氛围”

两个镜头都写“电影感夜景”，仍可能一个脸部左侧受光、另一个右侧受光；一个背景冷蓝、另一个突然暖黄。需要记录：

- 主光来自画面哪一侧、相对人物大致高度；
- 角色脸上哪一侧更亮；
- 背景主要色温与明暗层级；
- 是否有会跨镜移动的光源，例如车灯、闪电或手机屏幕；
- 光线改变有没有可见原因。

如果镜头 B 需要反打，不要机械复制“画面左侧来光”，而要保持同一个空间光源对人物的相对方向。

## 声音：画面切了，空间不一定要断

连续环境底可以让不同机位仍然属于同一空间。雨声、空调低鸣、远处交通和房间混响如果在切点突然重置，视觉再接近也会暴露拼接。

[Adobe Premiere 的 J / L Cut 文档](https://helpx.adobe.com/ie/premiere/desktop/edit-projects/trim-clips/perform-j-cuts-and-l-cuts.html)把声音与画面在不同时间切换的方式分成：

- **J Cut**：下一镜的声音先进入，画面随后切换；
- **L Cut**：画面先进入下一镜，上一镜的声音继续延伸。

可以这样安排：

```text
镜头 A：她抬头，先听见画外列车鸣笛。
J Cut：列车声音先出现。
镜头 B：切到远处驶来的列车，鸣笛继续。
```

或者：

```text
镜头 A：她说完“别打开”。
镜头 B：画面已经切到信封特写，但她最后一次呼吸仍延续片刻。
L Cut：声音把表演带过切点。
```

J / L Cut 是剪辑方法，不意味着所有声音都应该重叠。关键动作音效需要明确只出现一次，环境底需要连续，而对白是否跨切点取决于叙事节奏。

## 一张相邻镜头接口卡

每一对重要切点只需要记录：

```text
镜头对：A → B
切点类型：动作匹配 / 视线匹配 / 声音先行 / 声音延续 / 明确跳切

A 的出口：
- 人物位置与朝向：
- 视线方向与目标：
- 动作阶段与速度：
- 道具接触状态：
- 光线和环境声：

B 的入口：
- 怎样接住 A：
- 哪些内容保持：
- 哪些内容允许变化：

切点锚点：只列 3–5 个观众最容易追踪的事实
声音交接：硬切 / J Cut / L Cut / 环境底连续 / 刻意静音
验收重点：本切点最重要的 2–3 项
```

如果一张接口卡写了十几个“绝对不能变”，说明两镜可能没有清楚的主任务。先保留最重要的视觉和声音锚点。

## 常见断裂，先查哪条线

| 症状 | 先检查 | 优先修改 |
| --- | --- | --- |
| 人物突然换到画面另一侧 | 空间轴线、进出方向、是否越轴 | 调整机位或加入重新建立空间的镜头 |
| 两个人看起来没有看向彼此 | 左右视线、高度、距离与原始双人镜头 | 重新生成其中一个反打入口帧 |
| 动作像重复播放 | A 的结束阶段与 B 的开始阶段 | 让 B 从动作下一阶段开始，剪掉共享停顿 |
| 手中道具换边或恢复原状 | 持物手、开合状态、接触关系 | 使用道具状态锚点重做入口关键帧 |
| 切镜后人物还是本人但不像同一时刻 | 表情、姿态、发丝、服装褶皱与光线 | 缩小切点前后的状态差异 |
| 背景看似相似但空间不可信 | 门窗结构、景深、光源与人物相对位置 | 先建立场景母版和机位图 |
| 雨声或房间底噪突然重启 | 环境底是否被每镜独立生成 | 用连续环境轨贯穿切点，再叠局部音效 |
| 切点非常突兀但找不到画面错误 | Eye trace、运动速度、声音交接 | 调整切点位置，或使用 J / L Cut 提前承接 |

## AI 镜头最小连续性测试

不要一开始就连续生成十几个镜头。先选故事里最难的一对 A → B：

1. 准备人物锚点、场景锚点与道具状态；
2. 写出 A 的出口和 B 的入口；
3. 只保留 3–5 个切点锚点；
4. 分别生成 A 与 B，不急着评价单镜美感；
5. 把两镜放进真实时间线，先不加转场特效；
6. 循环播放切点前后约两秒，检查六条连续线；
7. 一次只修改一条线，例如先修动作，再修声音；
8. 保存“哪一层变了、为什么重做”的记录。

这里的“两秒”只是检查窗口建议，不是模型或剪辑标准。真正范围应根据动作速度和对白节奏调整。

## 什么时候应该保留不连续

连续不是唯一目标。跳切、越轴、突变光线、突然静音都可以成为叙事语言。保留它们之前，至少回答：

- 观众应该感到时间跳跃、空间混乱还是人物主观失衡；
- 哪一条连续线被打破，其他线是否仍提供方向；
- 这个变化在故事节奏上出现在哪里；
- 它在多次观看中都表达同一个意图，还是随机生成误差。

**可重复说明的破坏是选择，无法定位原因的破坏才是失控。**

## 生成前检查表

- [ ] 已把本轮检查单位写成镜头 A → 镜头 B；
- [ ] A 的出口和 B 的入口都有明确状态；
- [ ] 人物身份、空间方向、视线、动作、场景事实和声音已分别检查；
- [ ] 已决定是否保持 180 度轴线，若越轴已有叙事原因；
- [ ] 动作交接写清阶段、方向、速度和接触关系；
- [ ] 人物与关键道具都有不能漂移的锚点；
- [ ] 已区分直接沿用尾帧和重新设计入口关键帧；
- [ ] 环境底、对白和关键音效知道如何穿过切点；
- [ ] 切点锚点控制在 3–5 项，失败后可以定位问题。

## 剪进时间线以后再验收

1. **静音看一遍**：空间、视线和动作是否连续；
2. **闭眼听一遍**：对白、环境和音效是否突然断裂；
3. **逐帧看切点**：共享帧、重复动作、道具与肢体是否跳变；
4. **正常速度循环**：观众注意力是否顺利进入下一镜；
5. **去掉转场特效**：确认问题不是被叠化或模糊暂时遮住；
6. **记录修改层**：只重做真正断裂的一层，而不是自动推翻两镜。

## 最后记住这句分工

**单镜负责发生，切点负责交接。**

不要等全部镜头生成完，才发现人物一直在换边、动作总从头开始、雨声每五秒重启。先让最难的一对镜头真正接起来，再把已经确认的连续性规则带到后续分镜。
