> 方法骨架由荆提供；本文的组织、模板和补充说明是 AI 编辑候选，待荆确认。这里是一套工作检查框架，不是行业统一标准，也没有实际视频评分或模型排名。

一段视频可能很好看，却没有执行指定动作；也可能主体稳定，但动作接不上。把这些问题压成一个总分，后续就很难判断应该改 Prompt、补数据，还是重新定义验收标准。

八个维度固定的是观察位置，不是所有项目共用一套权重。开始前先写清任务、适用项和通过条件，结束时留下证据。

## 先固定评测条件

保留原始 Prompt、输入素材版本、生成参数中可获得的部分、模型版本、输出文件 ID、评测规则版本和评测人。未知参数写“未知”，不能补猜。

先按正常速度完整观看，再定位疑点并逐帧复核。播放卡顿与文件本身的跳帧要分开；单帧截图可以证明局部结构问题，不能独自证明时序连续。

## 八维分别看什么

### 1. 语义遵循

核对主体、数量、属性、动作、场景、风格、情绪、镜头要求以及明确限制条件。把 Prompt 拆成可观察的要求，再逐项记为满足、不满足、无法判断或不适用。

“出现了主体”不等于“执行了动作”。文字要求与画面证据之间应能一一对应；要求本身有歧义时，先退回澄清。

### 2. 基础画质

检查清晰度、模糊、噪点、伪影、边缘异常和局部纹理失真。说明异常位于哪里、持续多久、是否影响任务。

有意的景深虚化、运动模糊与生成缺陷不能只凭“模糊”二字混为一谈，要结合焦点和镜头意图判断。

### 3. 美学表现

观察构图、视觉焦点、色彩、光影、层次、质感、风格统一与画面完成度。记录为什么某处影响阅读或情绪，不只写“高级”“不好看”。

美学判断保留人工评测和分歧。风格偏好不应悄悄替代已约定的任务标准。

### 4. 主体与场景一致性

检查人脸、发型、服装是否漂移，物体结构是否变化，背景是否突然重构；镜头变化以后，主体身份能否保持。

这里关注“是不是同一个”。如果剧情明确要求换装或场景转场，应按剧情验收，而不是把一切变化判成错误。

### 5. 时序与动作连续性

检查动作断裂、瞬移、轨迹异常、重复动作和前后状态不连续。记录动作开始、关键转折、结束状态，以及异常发生的时间段。

这里关注“变化是否接得上”。主体外观没变，也可能在两个连续时刻之间跳过必要动作。

### 6. 结构与物理合理性

检查多指、少指、肢体融合、穿模、碰撞和接触关系，以及重力、水、烟、布料运动、阴影与倒影。

先确认作品约定的世界规则。超现实设定可以改变物理前提，但不能以“这是幻想”为由忽略作品内部的自相矛盾。

### 7. 镜头语言与叙事

检查景别、机位、运镜、镜头切换、镜头动机、信息呈现顺序、情绪节奏与故事完整度。

单镜动作测试不必硬评完整故事；没有切镜任务时，切镜项可记不适用。若要求完整短片，就要检查信息是否足以支持结尾。

### 8. 音画与安全

有声音时，检查嘴型与对白、动作与音效、环境音、音乐与情绪，以及声音连续性。不要只看波形对齐，还要听内容与节奏是否对应。

**无声任务的音画子项记为不适用，不自动给满分。** 如果任务明确要求声音却没有声音，应记录缺失，而不是不适用。

安全、版权与合规风险仍须单独检查。无声不代表免检；明显风险进入复核，来源和使用权未确认时保留待核查状态，不能把视觉检查当作法律结论。

## 一条记录怎样写

下面是空白工作模板，不代表已完成评测：

```text
样本 ID / 输出版本：待填
任务要求 / 规则版本：待填
主维度 / 辅助标签：待填
异常时间段 / 画面位置：待填
预期表现：待填
实际观察：待填
证据文件或帧号：待填
严重度 / 对任务的影响：待评
原因假设：待验证，不等同于观察事实
处理建议 / 责任角色：待定
复验版本 / 复验结论：待执行
```

严重度可先约定为阻断、主要、次要，再为每档补项目内正反例。同一段穿模既影响物理又影响时序，可以加辅助标签，但按样本统计失败率时不要重复计算同一条输出。

## 评测集分开看

| 集合 | 用途 | 报告边界 |
| --- | --- | --- |
| 标准测试集 | 保留固定核心，比较模型版本 | 规则与条件相同才直接比较 |
| Bad Case 集 | 跟踪历史高频失败和修复 | 专项结果不代表全部业务分布 |
| 压力测试集 | 覆盖遮挡、多人、细字、长视频、多镜头等复杂情况 | 单列难度与样本来源 |

评测材料要与训练材料去重，避免同源近重复样本泄漏。除固定核心外，新增专项样本独立标明版本；不要一边更换题目，一边把分数变化全归因于模型提升。

## 方法与报告相互对应

主观评测可以采用匿名 A/B 对比与多人独立打分。安排展示顺序平衡，允许持平和无法判断；先保留个人记录，再按规则处理分歧。

Prompt 遵循、OCR、图文一致性、帧间一致性和重复错误率等可以提供辅助证据，但必须声明计算方法、适用条件和分母。自动评分不直接替代美学、偏好、自然度的人工判断。

报告至少说明：评测范围、各集合样本量、八维问题分布、严重度、代表性证据、评测分歧与局限。没有统一权重时，不强行合成总分；存在阻断风险时，也不能被高美学分抵消。

下一步是把问题送入 [Bad Case 复盘闭环](/notes/bad-case-review-loop/)，而不是在“模型不好”这一句停下来。
