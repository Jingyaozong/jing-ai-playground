第一支 AI 漫剧最容易从“先生成几个漂亮镜头”开始，也最容易在人物不一致、动作不可用、镜头接不上以后重新来过。

更可靠的起点不是模型，而是交付定义：**要做多长、给谁看、故事完成什么、哪些错误会让镜头直接不可用。** 然后把制作拆成一连串小型验证，让最贵的批量生成发生在故事、人物和高风险动作已经通过之后。

> [!KEY POINT]
> 这篇是制作路线图，不是已完成复盘。所有“通过”都必须由真实文件、参数、样本和剪辑证明，不能用计划文字代替结果。

## 先定义“做完”是什么

对第一支作品，目标不必是建立完整宇宙，而是完成一个可以从头看到尾、能被复盘的最小闭环。

```text
交付物：一支 60—90 秒、16:9 的叙事短片
核心观众：第一次接触这个故事的人
核心问题：如果每天都会忘记昨天，还会不会重新选择同一个人？
完成标准：故事可理解；人物可识别；核心动作成立；声音完整；来源与生成记录可追溯
不追求：每镜都炫技、所有对白做口型、一次生成直接成为成片
```

| 层级 | 最低完成要求 | 暂时可以接受 |
| --- | --- | --- |
| 故事 | 开头提出问题，结尾产生选择 | 世界观没有展开完整 |
| 画面 | 主角身份可识别，关键道具和空间关系成立 | 次要背景细节存在变化 |
| 动作 | 每镜核心动作有起点、过程和终点 | 非关键微动作略有差异 |
| 剪辑 | 镜头顺序、时长和声音能支撑完整观看 | 少量镜头由静帧或替代素材承担 |
| 记录 | Prompt、输入、模型版本、日期和结果可追溯 | 尚未形成模型级结论 |

这份标准会阻止项目无限扩张。第一支作品的价值，是建立下一支作品可以复用的流程和问题清单。

## 一条路线，十个阶段门

| 阶段 | 必须产出 | 通过以后才能做什么 |
| --- | --- | --- |
| 0. 制作简报 | 时长、画幅、受众、核心问题、完成标准 | 选择故事 |
| 1. 故事种子 | 一句话、人物欲望、限制、转折、结尾选择 | 写节拍 |
| 2. 时间剧本 | 分段时长、画面、对白、声音 | 拆镜头 |
| 3. 分镜表 | 一镜一任务、景别、动作、运镜、声音、风险 | 做视觉设定 |
| 4. 视觉圣经 | 人物锚点、场景规则、色彩、可变与不可变项 | 生成关键帧 |
| 5. 关键帧 | 主要场景与高风险镜头的起始图 | 做动作小样 |
| 6. 动作小样 | 高风险镜头的真实视频结果与验收记录 | 批量生成 |
| 7. 镜头生产 | 可追溯的素材、参数和版本 | 进入剪辑 |
| 8. 剪辑与声音 | 可完整观看的时间线 | 最终评测 |
| 9. 复盘与发布 | 问题、证据、结论边界和公开版本 | 开始下一轮 |

任何阶段没通过，就停在当前阶段修正。不要用下游工作掩盖上游问题：故事没成立时继续生成，只会得到更多无法剪进成片的素材。

## 阶段 0：制作简报只回答五个问题

1. **给谁看？** 是第一次看到故事的普通观众，还是研究生成模型的人；
2. **看完记住什么？** 只保留一个核心问题或情绪转变；
3. **交付在哪里？** 横屏网站、竖屏社交平台或两种版本；
4. **限制是什么？** 时长、可用工具、预算、设备、版权与发布时间；
5. **怎样算完成？** 用可检查的句子，避免“足够电影感”。

```text
通过条件：不读设定说明的观众，也能在 90 秒内理解她会失忆、信件来自昨天的自己、结尾是她重新选择。
```

如果一句话写不清楚交付，后面的 Prompt 也不会替项目作出选择。

## 阶段 1：从故事问题开始，不从模型能力开始

先写角色面临的选择，再寻找 AI 能完成的表现方式。一个适合短片的故事种子至少包含：

- 主角现在想要什么；
- 有什么规则或限制挡住她；
- 今天发生了什么变化；
- 她最后做出什么选择；
- 哪一个视觉物件可以贯穿全片。

本站的[故事种子生成器](/tools/story-seed/)可以给出第一版组合，但生成结果只是候选。人工要继续判断它是否具体、可视、能在目标时长内结束。

```text
人物：每天醒来都会忘记昨天的女性
限制：记忆每天清零，信件只能保存事实，不能替她决定
变化：她必须重新认识一个正在告别的人
选择：不再证明过去，而是给明天留下新的选择
贯穿物：写给明天的信
```

**阶段门：** 一句话可以同时说出人物、限制和选择；删掉模型、画面风格以后，故事仍然成立。

## 阶段 2：把 90 秒先分给剧情，再分给镜头

不要边写 Prompt 边决定故事节奏。先用六个剧情节点分配时间：

| 段落 | 时间预算 | 本段唯一任务 |
| --- | ---: | --- |
| 醒来 | 11 秒 | 建立陌生感和失忆事实 |
| 发现信 | 12 秒 | 解释规则，但不替人物做决定 |
| 重新认识 | 21 秒 | 用生活物件建立身份与关系证据 |
| 见面 | 17 秒 | 让两个人第一次真正面对选择 |
| 做出选择 | 16 秒 | 用行动代替解释 |
| 写给明天 | 13 秒 | 形成循环，同时留下新的判断 |

每一段都写画面、对白或旁白、环境声和转场理由。完整方法已经放在[如何把 90 秒故事拆成 14 镜](/notes/ninety-second-storyboard/)。

**阶段门：** 静态朗读剧本不明显超时；每段只有一个叙事任务；结尾不是突然出现的观点，而是前面选择的结果。

## 阶段 3：一镜只签一份任务合同

分镜表不是 Prompt 列表。它先规定每个镜头对成片负责什么：

```text
镜头：07 / 隔着玻璃见面
时长：5—7 秒
叙事任务：两人第一次对视，但仍有物理距离
景别：中近景
主体动作：她抬眼，与门外的人对视，轻微吸气
摄影机：固定
声音：门铃后保留街声与停顿
关键失败：脸部重影 / 视线错误 / 玻璃反射吞没五官
```

可以先用[分镜整理器](/tools/shot-list-cleaner/)把散乱文字拆成景别、画面、运镜、对白和声音，再为每镜增加时长、核心任务和关键失败。

### 给镜头标风险，而不是平均用力

| 风险级别 | 典型镜头 | 先验证什么 |
| --- | --- | --- |
| L1 | 固定镜头、单人物、微动作 | 身份、构图、基础运动 |
| L2 | 道具接触、简单运镜、单次转身 | 手物关系、视差、遮挡连续性 |
| L3 | 镜面、玻璃、双人互动、行走握手 | 反射、多人身份、物理接触与连续动作 |

**阶段门：** 所有镜头都有唯一任务；总时长落在目标范围；至少标出三条最高风险镜头，不把所有镜头都当成同一种生成问题。

## 阶段 4：视觉圣经先规定“不变”，再允许变化

视觉圣经不需要先做成厚设定集。第一版只要覆盖人物、场景、色彩和连续性。

### 人物不变项

```text
同一虚构女性，二十多岁；齐下巴黑色直短发；右侧蓝色矩形发夹；红色三角耳饰；黄色针织外套；自然皮肤质感；脸部比例稳定。
```

### 人物可变项

```text
表情幅度、手部姿势、外套褶皱和发丝细节可以随镜头变化，但不能改变年龄感、发型长度、发夹侧别、耳饰形状和主色锚点。
```

### 世界规则

- 清晨以浅蓝、奶油白和黄色为主；
- 傍晚加入珊瑚红，但不突然进入暗黑科幻风；
- 信件、照片和时钟是证据链，不随镜头凭空增殖；
- 具体文字尽量后期完成，不把字形正确性混入人物测试；
- 画幅先固定为 16:9，再评估是否需要竖屏重构。

[AI 图片 Prompt 指南](/notes/image-prompt-guide/)提供了主体、动作、构图、光线、色彩和材质的写法；[景别指南](/notes/shot-size-guide/)用来检查人物边界和留白。

**阶段门：** 任何协作者只看一页规则，也能指出“这还是不是同一个人、同一个世界”；每条不变项都能在画面中被观察。

## 阶段 5：先生成关键帧，不先生成全部视频

关键帧承担三个任务：确定主体身份、建立空间构图、为图生视频提供合理第一帧。第一轮不需要每镜一张精修图，可以先覆盖：

1. 清晨卧室与主角身份；
2. 信件、照片、时钟的俯拍证据桌面；
3. 傍晚咖啡馆与玻璃空间；
4. 夜晚写信的桌面与灯光。

每张关键帧要记录：

```text
资产编号：KF-07-v03
对应镜头：07
用途：玻璃门相遇镜头的第一帧
输入：人物参考 v02 + 构图草图 v01
模型与版本：待填写
Prompt：待填写
必须保留：脸、发夹、耳饰、左右人物关系、玻璃边界
本版问题：待生成后记录
是否进入动作测试：未决定
```

**阶段门：** 四个主要场景可以被识别；人物锚点在目标景别中可见；高风险动作的第一帧姿态、重心和留白支持下一步运动。

## 阶段 6：先做三条动作小样

不要按镜头顺序把十四条全部生成。先选最可能推翻流程的三条：

| 镜头 | 测试问题 | 为什么先做 |
| --- | --- | --- |
| 02 镜中的陌生人 | 转头时正脸、侧脸和镜像能否同步 | 同时检验身份、反射和遮挡 |
| 07 隔着玻璃见面 | 玻璃反射下眼神和人物身份是否稳定 | 复杂空间会暴露背景与面部问题 |
| 11 主动握手 | 行走中两只手能否完成接触 | 手部结构、双人互动和物体恒存风险最高 |

每条先做 5 秒、一个核心动作、固定或最简单摄影机。Prompt 里把主体、环境和摄影机运动分开，具体方法见[文生视频与图生视频 Prompt 指南](/notes/video-vs-image-prompt/)和[运镜词典](/notes/camera-movement-guide/)。

```text
样本：MT-02-A
输入图：KF-02-v04
保持：模型、版本、时长、画幅、人物参考
本轮变量：只测试坐起后转头看镜子
通过：人物与镜像动作同步；身份锚点稳定；停住一秒
失败：镜中换脸、反射延迟、发夹换边、肩部变形
结果：待生成
```

**阶段门：** 三个高风险问题都有真实样本和记录；至少知道哪些镜头可以按当前方案继续，哪些需要降复杂度、拆镜或换制作方式。

## 阶段 7：批量生成也要像制作，不像抽卡

动作小样通过后，再按风险从低到高生产：

1. 固定镜头和简单微动作，建立角色稳定基线；
2. 单一道具接触与简单运镜；
3. 双人、反射、复杂手部和空间变化；
4. 只在必要时追加替代镜头和过渡素材。

每一次生成都进入台账：

| 字段 | 必须记录 |
| --- | --- |
| 资产编号 | 镜头号、版本和候选标记 |
| 输入 | 参考图、首尾帧或其他控制素材 |
| 条件 | 模型、版本、日期、时长、画幅和可见参数 |
| 指令 | 完整 Prompt 与产品控件设置 |
| 结果 | 文件位置、通过/失败、严重度和问题原句 |
| 下一轮 | 只写一项待验证修改，不伪装成已知原因 |

真实结果可以进入[四十镜实验记录板](/experiments/forty-shots-one-character/#record-desk)。不知道问题叫什么时，用[AI 视频翻车词典](/notes/video-failure-cases/)识别身份漂移、闪烁、物体恒存、物理穿帮和运镜失控。

**阶段门：** 每个进入剪辑的镜头都能追溯到输入和条件；没有用“多抽几次”代替问题记录；关键失败不会被漂亮画面掩盖。

## 阶段 8：先有声音时间线，再追求每镜完美

剪辑不是把十四条视频按编号排列。更实用的顺序是：

1. 用草图、静帧或占位素材完成 animatic；
2. 放入临时旁白、对白、环境声和停顿；
3. 确认故事在目标时长内可理解；
4. 用真实视频逐镜替换占位素材；
5. 对无法通过的镜头决定降级、拆分、后期处理或重写；
6. 最后统一色彩、声音电平、字幕和输出规范。

声音要从剧本阶段存在。闹钟、拆信、纸页、咖啡杯、脚步和笔尖可以建立循环与现实感，不必等画面全部完成后才补。

```text
替代策略：如果镜头 11 的行走握手无法稳定完成，先拆成“照片被收起”的手部特写和“停下后握手”的固定特写；叙事任务不变，动作复杂度下降。
```

**阶段门：** 时间线可以从头看到尾；即使部分镜头仍用明确占位，也能判断节奏、信息和声音是否成立；所有占位都列入待替换清单。

## 阶段 9：评测决定下一步，不负责制造高分

成片验收至少分四层：

- **任务完成**：故事与每镜核心动作是否发生；
- **连续性**：人物、道具、空间和时间是否接得上；
- **人体与物理**：手、重心、接触、反射和遮挡是否可信；
- **表达与用途**：注意力、节奏、声音和画幅是否服务发布场景。

使用 PASS、MINOR、MAJOR、CRITICAL 决定保留或返工，具体流程见[AI 视频到底应该怎么评](/notes/ai-video-evaluation/)。核心动作缺失、身份不可确认或严重人体崩坏属于关键失败，不能被光线和画面风格的优点抵消。

**阶段门：** 所有关键失败已经处理或公开标记；输出文件在目标设备上播放正常；字幕、声音、链接和来源信息完成最终检查。

## 复盘只写证据能支持的结论

完成第一版后，制作记录应该回答：

1. 原定计划与最终成片有哪些变化；
2. 哪些镜头通过，哪些镜头被拆分、替换或放弃；
3. 真实使用了哪些模型、版本、参数和参考素材；
4. 最常见失败出现了多少次，发生在哪些条件下；
5. 哪些修改只在单个样本上有效，哪些经过了重复验证；
6. 下一支作品会保留、删除或新增哪一步。

“这个模型不擅长手”“某种 Prompt 一定更稳定”都需要足够样本和清楚条件。一次偶然结果只能写成观察或下一轮假设。

## 当前项目真实状态

截至这份路线图编辑时，网站内已经存在：

- 90 秒故事梗概、人物关系与一天时间线的编辑草案；
- 六段时间剧本和十四镜分镜第一版；
- 人物身份锚点、色彩方向和逐镜 Prompt 包；
- 镜头 02、07、11 的动作测试设计与通过/失败标准；
- 可填写的实验记录板、失败词典和评测方法。

仍然没有完成：

- 经过统一模型与参数实际生成的三条动作测试；
- 可供复核的完整原始视频样本与参数台账；
- 十四镜候选素材、完整剪辑、声音和字幕；
- 基于真实结果的制作结论与成片发布。

这就是为什么本文标记为**编辑稿**，而不是“我的第一部作品复盘”。路线已经可以执行，但过程与结论必须等真实素材进入以后再写。

## 下一次真正开工时的七个工作单元

| 单元 | 只完成一件事 | 输出 |
| --- | --- | --- |
| 01 | 确认核心问题、人物名字、结尾和发布画幅 | 锁定制作简报 v1 |
| 02 | 朗读并调整六段剧本、旁白和声音 | 90 秒时间剧本 v2 |
