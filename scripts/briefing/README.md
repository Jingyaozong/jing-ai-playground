# 本地 AI 简报采编（第一阶段）

这是本地命令行流程，不是公开网站功能，不会定时运行、push 或发布。
现有网站和部署配置保持不变。所有输出位于已被 Git 忽略的 `work/briefing/`，不会进入 `content/notes/` 或静态导出。

## 使用

1. `npm run briefing:demo`：离线生成明确标注为虚构样例的 Markdown 审阅稿，无网络、无 API 费用。
2. `npm run briefing:collect`：读取白名单官方 RSS，收集近七日候选。同步保存同名 JSON 和可阅读的 Markdown 清单，终端提供路径。清单含来源摘要、日期、原文链接和核对勾选框；无模型费用，不是全文核实。文件只在私有工作目录，不进入公开网页。清单勾选仅供人工阅读，不会触发批准、发布或影响 draft 的选稿。
3. 在本地 `.env.local` 设置 `DEEPSEEK_API_KEY`（不要提交、截图或粘贴到聊天）。
4. `npm run briefing:draft`：重新读取来源，调用一次 DeepSeek Flash，输出最多五条待审内容。终端打印稿件路径，可用 Markdown 预览打开。

模型接口与 JSON 格式依据：https://api-docs.deepseek.com/api/create-chat-completion/
来源包括 Hugging Face 官方博客 RSS、Google AI 官方博客 RSS 和量子位官网 RSS；不代表覆盖全网 AI 新闻或公众号全量。

## 编辑约束

### 先选文章，再生成（可选）

运行 `npm run briefing:review`，打开 `http://127.0.0.1:4318/` 即可勾选文章（最多五篇），复制免费的预检命令。仍需在项目终端执行；页面没有付费生成或发布按钮。复制不可用时会选中命令供手动复制。

勾选自动保存在当前浏览器 localStorage，刷新可恢复。只保存序号，以候选文件名和完整内容的哈希隔离批次；换文件、改变顺序或内容不会误套旧选择。不保存正文、密钥，不跨浏览器或设备同步，不代表审批。清空选择会移除本批存储记录。存储被禁用、已满或损坏时显示提示，当前勾选仍可用于复制；清除失败时刷新可能恢复旧记录。多个同批页面不实时互相同步，以最后一次操作为准。

这是独立的本地开发预览进程，不是生产服务器：只监听本机 127.0.0.1，仅返回单页，不提供文件目录、API、写入接口或密钥；不改 Next.js 和 GitHub Pages。只加载启动时最新的候选 JSON，重新采集后需重启预览。Ctrl+C 关闭。过期或无效清单会停止启动，请重新采集。网页不下载字体、图片或第三方脚本；原文链接只有主动点击才访问外部网站。

新采集的 Markdown 清单按 JSON 中的顺序显示序号。旧清单未显示序号时按文章顺序从 1 数起。指定同批次 JSON 的文件名和一至五个序号：

```sh
npm run briefing:draft -- --file candidates-1788859143946.json --pick 1,3 --check
```

将示例文件名替换为实际清单文件名。`--check` 只做本地预检，显示选中内容，不联网、不需要密钥、不占用每日请求机会。确认后移除 `--check` 才会调用付费模型，并沿用每日一次保护。选择模式不重新采集、不替换候选；清单或文章超七日、日期异常、序号不存在、来源不合法、ID 不匹配、已生成过待审稿时停止。模型仍可跳过不适合写作的选中条目，不保证每篇都产出。

不带选择参数的旧命令仍会重新采集并让模型筛选。勾选 Markdown 不是选稿指令，更不是发布批准；选稿也不代表事实核验完成。

固定结构：标题、事实摘要、创作关联（编辑推测）、核对边界、来源和订阅发布时间、待确认观点、配图状态、审核清单。
只据订阅摘要生成。事件日期、产品效果、价格、个人观点都不能猜测。厂商自述不是独立评测。
不抓取全文、不下载外部图片、不自动生成个人观点。模板与公开页面将来由人工确认后对接；不要直接把审阅稿移动到笔记目录。
模型返回的来源 ID 必须来自输入；链接由程序回填，模型不能生成新链接。模型不拥有文件、命令、Git 或浏览工具。
输入内容是数据，不是指令；结构校验不能证明事实真实，人工对照原文仍不可省略。

## 运行边界

- 近七日、最多十二条候选、单次最多 2500 输出 tokens、最多五条简报；无自动重试。
- 单条输入仅保留标题和最多 800 字符摘要；响应大小和请求时长有限制。
- 只访问固定 HTTPS 来源；拒绝跳转、站外文章链接、DTD。解析范围是 RSS 2.0 的 title/link/pubDate/description，不是通用 XML 抓取器。
- 未来日期、缺日期、过期条目丢弃；按规范化 URL 去重。既有真实待审稿里的来源不重复入选；这不是跨来源事件聚类。
- 任意来源失败则停止，不用模型编造补位。无候选不收费；空模型精选不凑数。
- 不覆盖旧稿件。真实稿件清单损坏时停止，避免静默绕过去重。
- 密钥仅在 Node 进程环境中使用，只发到固定 DeepSeek HTTPS 接口。错误不打印请求头或供应商响应正文。
- 北京时间每天最多发起一次模型请求：调用前以排他写入记录到 `work/briefing/.requests/日期.json`，并发运行只放行一个。无密钥、来源失败、无候选时不会占用机会；demo/collect 不占用。
- 请求失败、超时或保存草稿失败时也保留记录，因为供应商可能已经计费。没有自动重试或强制绕过开关；需先人工核对账单与稿件，再决定是否处理该日记录。不要直接删记录后反复试跑。
- 这是请求次数保护，不是金额硬预算；另有单次输入和输出限制。当前没有月度金额硬上限，启用定时运行前仍需预算配置、失败通知，并由荆明确授权。
- 不自动读取或改写现有笔记、个人介绍、经历、作品成果或网站 CSS。
