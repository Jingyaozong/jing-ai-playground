# 分类导航回归检查

在项目根目录执行：

```sh
npm run build
npm run verify:navigation
```

使用 Node 自带测试运行器，无需安装依赖。必须先构建，检查读取当前 `out/`，不会自动判断导出是否过期。

自动覆盖：

- 笔记、收藏实际共用的网址解析和写入函数：合法值、空值、未知值、异常编码、空格编码、全部重置、保留其他参数与锚点、重复选择。
- 静态 HTML 中四个笔记栏目、五个收藏分类的真实链接（排除 React 的脚本数据）。
- 每篇 Markdown 笔记导出的顶部和文末栏目返回链接。
- 全部笔记，包括重点笔记，在导出的搜索列表中可用。

不覆盖 React 水合、点击事件、浏览器历史或视觉布局。修改导航后仍需在本地浏览器检查：分类点击、搜索与分类组合、空结果重置、刷新、前进/后退，以及桌面和 390px 手机排版。

新增栏目时需同步测试中的预期分类列表；笔记详情与搜索覆盖范围自动读取 `content/notes/`。
